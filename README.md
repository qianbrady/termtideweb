# TermTideWeb

Paste numbers (JSON array or CSV) → deterministic gradient SVG charts: **sparkline · heatmap · bars**, three themes, download or copy the SVG source.

**Live tool:** https://qianbrady.github.io/termtideweb/ · 纯离线单文件。

![License](https://img.shields.io/badge/license-MIT-green)
![Offline](https://img.shields.io/badge/network-none-blue)

Byte-faithful port of [termtide](https://github.com/qianbrady/termtide)'s SVG engine — same THEMES, same gradient interpolation, same printf-style formatting. Verified byte-exact against the Python original on sparkline/heatmap/bars fixtures.
